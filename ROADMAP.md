## v1.1 — Стабилизация (текущий приоритет)

- [x] Поворот OLED-дисплея (`rotate` параметр) для физически перевёрнутого монтажа
- [x] Диагностика аудио-устройств при запуске (`audio_diag.sh`, логи в ноде)

## v1.2 — Анимированные эмоции

Большинство эмоций — статичные кадры. Частично сделано: `sleepy` без своего PNG — сигарета + дым. Планируется:ав
- [ ] Анимация перехода между эмоциями (плавный морфинг или fade)
- [ ] «Дыхание» рта в режиме idle для нейтральной эмоции (не только sleepy)
- [ ] Анимация говорения — рот двигается в такт осциллограмме (не просто линия, а стилизованные формы рта)
- [ ] Поддержка GIF-анимаций в `resources/emotions/` (многокадровые)
- [ ] Параметр `animation_fps` в конфиге для управления частотой кадров
